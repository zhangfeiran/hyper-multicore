# 专家副本性能验证协议

## 固定工作负载

主要比较场景为EP32、E192、H5120、I1792、TopK8、BF16、4096 token/rank，B6 Push。
使用真实AdamW、`foreach=False`。F+B包含count/plan、派发、专家计算、归还和autograd；
完整step另包含优化器，两个口径分别报告。

输入、参数、上游梯度、概率及路由字节必须跨实现和进程核对。
baseline、candidate和PR7各自记录实际源码及每个原生组件的哈希；B和准入规则保持可比。

## 路由扫描和统计

完整矩阵包含均衡、32个alpha及3个额外seed锚点，共36路由。
每臂4个新进程，交错三臂，后半组反向扫描；每点5次warmup与20次measured。
逐步取全部32-rank最大值，再对每臂每点80样本取pooled median，保留全部慢样本和四个独立对照块。
观察器和额外consumer调用不进入正式窗口。

alpha主网格为10000、5000、3000、1000、500、300、100、50、30、10、7、5、3、2、1.5、1、
0.7、0.5、0.3、0.2、0.15、0.1、0.07、0.05、0.03、0.02、0.015、0.01、0.007、0.005、0.003、0.001。
主网格seed83；均衡seed42，额外锚点为alpha0.5/0.01/0.005、seed42。

采用条件在采样前冻结：无副本对PR7最差回退不超过1%，全部副本点领先PR7；
相对当前基线，热点中位至少改善0.2%、至少18/26点改善、热点最差回退不超过1%，
且至少3/4独立块同方向。功能、输入、实际路径和资源审计也必须通过。
早筛仅决定是否进入完整矩阵，不能以少数锚点替代完整采用资格。

## HBM与终态

分别报告最大rank allocator allocated/reserved、平均rank峰值、SHMEM和间隔采样进程HBM。
这些口径不能相加；跨整轮约3秒采样最大不是每alpha的连续物理峰值。
仅减少平均rank内存，也不能宣称最大rank容量改善。

每个rank/case必须有终态；同时检查两节点退出、foreign PID、设备健康、任务PID、锁和relay释放。
失败或中断的cohort保留原件，不复用其计时，也不按结果调整统计口径或采用阈值。
新代码的CPU/编译资格、设备功能和正式性能分别记录。
